Features

Your essential FP-30X controls in one place

🎹

153 Tones

Browse and load the 153 documented tones in PianoPilot's FP-30X catalog — including Piano, E.Piano, Organ, Strings, Pads, GM2, and more — instantly sent over MIDI.

🎚️

Piano Settings

Master Volume, Key Touch, Brilliance, Transpose, Master Tuning (Hz display), and Ambience Depth — all in a single, comfortable panel.

🎛️

Split, Dual & Twin Modes

Configure keyboard modes with independent tone selection, balance, octave shifts, and a draggable split point — without touching the piano.

🥁

Full Metronome Control

Set BPM (10–500), volume, click tone (Electronic, Voice…), and time signature with subdivision patterns. Start/stop without leaving your seat.

💾

Presets

Save, apply, edit and delete tone configurations for Single, Split, Dual and Twin modes, including the piano settings. Import and export presets as a JSON file to back them up or share them.

🔌

USB & Bluetooth

USB MIDI is the recommended connection. System-paired Bluetooth MIDI also works when the FP-30X is available to the operating system; Bluetooth Audio is not used.

🔄

Two-Way Sync

Optionally reads the piano's current state over MIDI input so the UI always reflects what the instrument is actually doing.

🌐

English & Spanish

Full bilingual interface. Switch between English and Spanish at any time without restarting the application.

Before you connect

Built specifically for the Roland FP-30X

One supported piano model

PianoPilot targets the Roland FP-30X MIDI implementation. Other Roland models are not currently supported.

USB MIDI is recommended

Connect the piano to the computer by USB and select its MIDI input and output in PianoPilot.

Bluetooth MIDI is optional

Pair Bluetooth MIDI in the operating system first. Bluetooth Audio is a different connection and is not used by the app.

The operating system usually supplies the MIDI driver, but some Windows configurations may require an additional driver or pairing utility.
