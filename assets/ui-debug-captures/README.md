# Capturas de depuración (UI)

Guarda aquí las capturas de pantalla que uses al depurar layout Qt/Tk.

Todo el contenido de esta carpeta está en `.gitignore` excepto este `README.md`.

En la raíz de `assets/`, `.gitignore` ignora patrones típicos de capturas de depuración
(`generation_full_*.png`, `overlay_mode_*.png`, `*_smoke.png`, etc.) sin tocar los recursos
reales (`app_logo*.png`, `piano.png`, `guitar.png`, `metronome.png`, etc.).
